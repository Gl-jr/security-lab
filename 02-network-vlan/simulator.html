Тренажёр VLAN: разделяем офис

Один коммутатор, три отдела. Настрой VLAN командами Cisco IOS и проверь, кто кого видит.

Схема сети

Switch
VLAN 1 (по умолчанию) VLAN 10 VLAN 20 VLAN 30

Задание

0 / 5

    Начни так: введи enable, затем configure terminal. Команды можно сокращать: conf t работает так же.

    Консоль коммутатора

    Шпаргалка по командам
    • enable — режим администратора
    • configure terminal — режим настройки
    • hostname SW1 — имя устройства
    • vlan 10 → name BUH — создать VLAN с именем
    • interface range fa0/1 - 8 — выбрать группу портов
    • switchport mode access — порт для конечного устройства
    • switchport access vlan 10 — назначить порт в VLAN
    • show vlan brief — какие порты в каком VLAN
    • show running-config — текущая конфигурация
    • exit / end — на уровень назад / в начало
    • write memory — сохранить настройки

    Проверка связи

    Выбери два компьютера и нажми ping.

    Тренажёр воспроизводит подмножество команд Cisco IOS: коммутатор второго уровня, режим access, проверка связи по ICMP. Маршрутизатора в схеме нет — это следующий этап.
