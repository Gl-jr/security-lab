# Security Lab — практическое портфолио по информационной безопасности

Домашняя лаборатория для отработки настройки и тестирования средств защиты информации:
WAF, межсетевых экранов, IDS/IPS, SIEM, NGFW и антивирусной защиты.

Каждая работа содержит: цель, схему стенда, конфигурации, ход выполнения, результаты и выводы.

## Стенд

| Устройство | Роль |
|---|---|
| MacBook Pro M1 Pro, 16 ГБ | Основной хост: Docker, UTM, Cisco Packet Tracer |
| MacBook M2, 8 ГБ | Машина «атакующего» |
| x86-ноутбук Lenovo | Продукты, требующие x86: KSC, NGFW |

## Интерактивные тренажёры

| Тема | Что внутри |
|---|---|
| Топологии сетей | пять топологий с проверкой на отказ: обрыв кабеля и узла, распад сети на сегменты |
| Путь пакета по уровням (OSI) | пошаговая инкапсуляция запроса, что читает каждое устройство, атаки по уровням |
| Разбор чужой сети | генератор офисных схем с типовыми ошибками и 50+ заданий с проверкой |
| Тренажёр VLAN | консоль Cisco IOS, настройка VLAN, проверка связи между отделами |
